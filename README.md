# Code Geass: *Lelouch of the Rebellion*

**Code Geass** is a *mecha anime series* set in an alternate future where the Holy Britannian Empire conquers Japan, renaming it *Area 11*.  
The story follows **Lelouch vi Britannia**, a prince who gains the mysterious power of **Geass** and leads a rebellion under the alias *Zero*.
